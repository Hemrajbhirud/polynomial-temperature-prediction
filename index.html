Mathematics & Code

Methodology & Implementation

Mathematical formulation of polynomial regression, the normal equations, and production-ready Python scikit-learn code.

1. Polynomial Projection
X = [ 1, x, x², x³, ..., xᵈ ]

Transforms scalar day input into a (d+1)-dimensional non-linear feature space via the Vandermonde matrix.

2. Ordinary Least Squares (OLS) Solution
c* = (Xᵀ X)⁻¹ Xᵀ y

Minimizes sum of squared errors ∑(yᵢ - ŷᵢ)². When x is raw elapsed days (up to 1,460), the matrix condition number cond(XᵀX) explodes, causing extreme numerical instability. Day of year (1..366) keeps features well-conditioned.

3. Combined Forecasting Model
ŷ(date) = P₈(day_of_year) + (m · year + b) - ȳ

Decomposes thermal prediction into an 8th-degree seasonal oscillation plus a linear year-over-year climate drift.

# Polynomial Curve Fitting on Delhi Climate Data
import numpy as np
import pandas as pd
from sklearn.metrics import mean_squared_error, r2_score

# 1. Load dataset & remove overlapping boundary date
train = pd.read_csv('DailyDelhiClimateTrain.csv', parse_dates=['date'])
test  = pd.read_csv('DailyDelhiClimateTest.csv',  parse_dates=['date'])
train = train[~train['date'].isin(test['date'])].reset_index(drop=True)

# 2. Key feature engineering: day of year
train['day_of_year'] = train['date'].dt.dayofyear
test['day_of_year']  = test['date'].dt.dayofyear

# 3. Fit optimal degree-8 seasonal polynomial
coefs = np.polyfit(train['day_of_year'], train['meantemp'], deg=8)
poly  = np.poly1d(coefs)

# 4. Evaluate on held-out 2017 test set
y_pred = poly(test['day_of_year'])
rmse   = np.sqrt(mean_squared_error(test['meantemp'], y_pred))
r2     = r2_score(test['meantemp'], y_pred)

print(f"Held-out 2017 Test RMSE : {rmse:.3f} °C")
print(f"Held-out 2017 Test R²   : {r2:.3f}")
# Result: RMSE = 2.873 °C, R² = 0.794
